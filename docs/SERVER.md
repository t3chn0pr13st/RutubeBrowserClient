# Серверная эксплуатация

1. Выполните интерактивный вход на доверенной рабочей станции.
2. Экспортируйте portable session file.
3. Передайте его через секретный канал и импортируйте в зашифрованный `IRutubeSessionStore`.
4. Удалите временную копию. Не передавайте сессию через аргументы процесса или логи CI.

`FileRutubeSessionStore` пригоден для локального использования: атомарная замена, `0600` файл,
`0700` каталог. В ASP.NET Core реализуйте `IRutubeSessionStore` поверх Data Protection/secret
storage. Одна account-session не должна одновременно перезаписываться несколькими процессами;
лидер worker должен сериализовать refresh и сохранять обновлённую сессию.

Окончательно истёкшая cookie/refresh session не открывает браузер внутри фонового HTTP-запроса:
API возвращает безопасную ошибку, после чего оператор импортирует обновлённую сессию.
